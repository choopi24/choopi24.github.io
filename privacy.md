# Privacy Policy for Hermesagent

Last updated: October 25, 2026

Hermesagent is a personal, self-hosted tool. It is used only by its owner and is not offered to the public.

## What data is accessed

With the owner's explicit consent through Google sign-in, Hermesagent may access the owner's own Google account data (for example email, calendar or files) only within the permissions granted.

## How data is used

Data is used solely to provide features to the owner. It is not used for advertising, profiling or any other purpose.

## Sharing

No data is sold, rented or shared with third parties.

## Storage

Any data or access tokens are stored only on the owner's own systems.

## Google API Services

Hermesagent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions
